# exp9 — агент Haiku: пошуковики пантеону проти пошуку в коді

**Питання.** Чи знайде LLM-агент файли для задачі краще з пошуковиками пантеону (gamayun, simargl,
svitovyd), ніж зі звичайним пошуком у коді?

**Сетап.**
- 10 задач sonar з тестового набору exp7: справжній текст, 1–5 змінених файлів, хоча б один із них є в
  поточному checkout (`prep.py`). Задачі розподілено між групами по черзі: **A1–A5** і **B1–B5** — це
  **різні** задачі.
- **Група A** — лише пошуковики пантеону через `tools.py`: `gamayun`, `show`, `simargl`, `find`, `defines`,
  `trace`. Онтологія exp7 побудована без тестових і dev-задач; simargl вирізає їх із результатів
  (`held_out()`). Читати код не можна.
- **Група B** — лише пошук у коді.
- Агенти Haiku, по одному на групу. Правильні файли — поза теками експерименту.

```
python prep.py truth.json                           # 10 задач -> tasks_A.md, tasks_B.md
python tools.py gamayun "<текст задачі>"            # те, що бачив агент A
python score.py truth.json out/answers.json         # оцінка
```

`truth.json` — правильні файли. Під час прогону він лежав поза репозиторієм, щоб агенти його не бачили;
тепер, коли експеримент закрито, перенесений сюди, щоб оцінку можна було повторити.

## Висновки й чому був exp9.1

1. Без читання коду агент A вгадував файли лише з рангів пантеону й промахнувся в 4 з 5 задач.
2. Порівняння некоректне в трьох місцях, і exp9.1 їх виправляє:
   - групи мали **різні** задачі;
   - код був на **HEAD**, тобто вже містив розв'язок;
   - групи відрізнялись не лише пантеоном, а й можливістю читати код.

   Після виправлення (exp9.1: ті самі задачі, checkout до розв'язку, читання коду в обох групах) MAP
   агента виріс до 0.80 / 0.77.
3. Вибірка зміщена: брали задачі, файли яких існують на HEAD, тобто «знахідливі» задачі з буквальним якорем.
   Це обмеження переходить і в exp9.1–exp9.6; exp9.7–exp9.8 шукають задачі без якоря.

`tools.py` (пошуковики пантеону без витоку відповідей) і `out/params_sonar.json` (параметри gamayun,
підібрані на dev) використовують усі наступні exp9.*.
