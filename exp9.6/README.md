# exp9.6 — Haiku з компасом і супутниками (C) проти Haiku exp9.1

**Питання.** Чи стануть нові команди gamayun — `compass` (з чого почати і наскільки впевнено) і
`companions` (файли, що змінювались разом із названими) — кілерфічею для агента Haiku?

**Сетап.**
- ті самі 10 задач, checkout'и й правильні файли, що в exp9.1;
- **група C** = група A exp9.1 (код + пантеон) + `compass <T> "<текст>"` і `companions "<шляхи>"`
  (`lab6.py`, `C/tool.py`), онтологія exp7 без відкладених задач;
- два агенти Haiku (T01–T05, T06–T10); A і B не переганялись, порівняння з exp9.1.

```
python C/tool.py compass T05 "Project creation form validation is buggy"
python score.py                      # out/answers_C.json -> out/score.md
```

## Висновки — і чому вони обмежені

1. **Кілерфічею не стало:** MAP 0.688 проти 0.797. Програш лише на двох задачах:
   - **T05:** компас поставив другим неправильний `CreateProjectPage.tsx`, агент прогнав супутників від нього,
     і супутники посилили хибний напрямок;
   - **T10:** компас («середня») вказав на фронтенд, а правильний файл був у бекенді.

   Виграш на T07 (0.44 проти 0).
2. **Порівняння нечисте — головне обмеження.** Промпт C змінив не лише інструменти, а й стратегію:
   «почни з компаса» замість «gamayun і simargl — сильний пріор». Агенти покликали gamayun 1 раз за 10 задач,
   simargl — 6, тож падіння на T05/T10 однаково пояснюється і інструментами, і підказкою. Тому exp9.8
   порівнює групи з **однаковими** промптами, які відрізняються лише списком команд.
3. **Стеля на легких задачах:** шість із десяти задач A і B розв'язують на 1.0 grep-ом за якорем; виграти
   там нічого не можна. Звідси exp9.7: пошук задач, де голка лежить глибше за слова задачі.
4. Агенти Haiku викликали компас неохайно: три виклики без id задачі, на T01/T02/T05 — лише заголовок без
   опису, тож якорі на кшталт `sonar.sso.groupsHeader` компас не бачив.
