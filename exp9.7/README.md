# exp9.7 — пошук глибоких задач: голка не там, куди вказують слова задачі

**Питання.** exp9.1–exp9.6 брали задачі з буквальним якорем — шість із десяти розв'язує один `grep`.
Теза: gamayun стає незамінним, коли ключ лежить глибше, «голка в яйці, яйце в качці…». Чи є такі
задачі в датасеті, і скільки їх?

**Відбір** (dev і test exp7, ~400 задач, T01–T10 виключено; онтологія exp7 без цих задач — без витоку):

| Крок | Умова | Задач |
|---|---|---|
| `find_deep.py` | немає рідкісного якоря (компас exp9.5 пішов в онтологію); файли у 2+ модулях; є **вхід** — правильний файл, на який слова задачі вказують напряму (`characterizes`, `names`); є **голка** — правильний файл, на який слова не вказують, але досяжний за один перехід (`co_changes_with` від входу або `depends_on` модулів) | 54 |
| `pick_deep.py` | 3–20 файлів (не масовий рефакторинг); вхід у топ-30 онтології і не хаб (не з 1 % найзв'язніших файлів — `core.properties` «змінюється разом» з усім); голка — серед 10 найсильніших супутників входу і поза топ-10 онтології | 8 |
| `pick_deep2.py` | без пар «клас ↔ його власний тест» (їх знайде grep за назвою класу); дозволено два переходи | 4 |
| `deep5.py` | + SONAR-1915 з першого відбору (кореневий `pom.xml` → `pom.xml` плагіна; фільтр двійників відкинув його лише через однакову назву `pom`) | **5** |

```
python find_deep.py      # -> out/deep.json
python pick_deep.py      # -> out/deep_picked.json
python pick_deep2.py     # -> out/deep_picked2.json
python deep5.py          # -> out/deep5.json, out/deep5.md
```

## Висновки

1. **Справжні «голки в яйці» рідкісні:** суворий відбір із ~400 задач лишив 5 (≈1 %). Більшість
   формальних кандидатів — масові рефакторинги, ланцюжки через хаби або пари «клас ↔ тест».
2. **gamayun сам ці задачі не розв'язує** (на двох — 0): вхідний файл у нього на 11–30 місці. Але вхід і
   зв'язок до голки в онтології є, тож це правильний тест на те, чи вміє агент по них пройти (exp9.8).
3. Найслабша — SONAR-17735 (ланцюжок через тести); SONAR-9253 — 12 з 19 файлів створює сама задача.
   Щоб висновки стали переконливими, потрібно більше таких задач — наприклад, з flink.

`out/deep5.json` — набір для exp9.8: текст, правильні файли, ланцюжок, коміт до розв'язку,
топ-10 gamayun. **Агентам цей файл не показують.**
